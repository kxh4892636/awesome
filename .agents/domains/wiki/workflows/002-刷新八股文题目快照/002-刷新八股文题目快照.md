# 002-刷新八股文题目快照

适用：想看 osjobs 最新一版面经高频题，或要改收录的 tag、调分组规则。产物是 `repos/wiki/docs/020-八股文梳理/` 下每 tag 一个 markdown。来源、口径与当初的切片在 [2026-11-12-八股文题目整理](../../plans/archived/2026-11-12-八股文题目整理/spec.md)。

## 现状（2026-11-21）

| 项 | 事实 |
| --- | --- |
| 脚本 | `repos/wiki/scripts/topk.mjs`（`fetch` / `render`）、`topk-groups.mjs`（分组关键词表）、`topk-snapshot.json`（2026-11-12 抓的 8 个 tag、721 行） |
| 产物 | 2 个文件、435 行：算法 316、非技术 42 |
| 与快照的差 | 2026-11-18（`5575ec7`）删掉已迁进知识笔记的题：`Golang.md` 整篇删除、`前端.md` 118 → 111；2026-11-21 随 [2026-11-21-八股文转知识笔记](../../plans/active/2026-11-21-八股文转知识笔记/spec.md) 把前端 / 操作系统 / 数据库 / 系统设计 / 网络协议删空，5 个文件删除，数据库里混入的 1 道算法题移进 `算法.md`（315 → 316） |
| 谁读谁 | `fetch` 按 `topk.mjs` 的 `TAGS` 抓并写快照；`render` 遍历 **`topk-snapshot.json` 的 `tags`**，不读 `TAGS` |

**所以别直接跑 `render`**：现在跑一次会把 6 个已删或已收缩的文件整个写回来（`Golang.md` 与 11-21 删掉的五个 tag 文件），覆盖 11-18 与 11-21 两轮人工删除。要重生成，先把这些去留定下来（改快照，或确认迁移已完成、删掉对应题）。

## 步骤

1. **定 tag 集**。改 `topk.mjs` 的 `TAGS` 决定 `fetch` 抓哪些 tag（顺序即 `sidebar_position`，也就是题数降序）；`render` 只跟快照，所以要少一个 tag 必须删 `TAGS` 里那行后重跑 `fetch`，或直接改快照。
2. **抓**：在 `repos/wiki` 下跑 `node scripts/topk.mjs fetch`（脚本头注释里的 `apps/wiki/scripts/` 是拆仓前的旧路径）。8 个串行请求；`data.next` 非空直接报错——接口开始分页就要补翻页；任一 tag 失败退出码 1、不写快照。
3. **生成**：`node scripts/topk.mjs render`。分组由 `topk-groups.mjs` 的有序关键词表决定：题干转小写后首个命中者胜出，落空的进「其他」，空组不出现。组顺序即表顺序，改分组只改表。
4. **校验**（脚本不查，自己核）：每行 `^- \d+ - .+`；每个 `## 组名（N）` 的 N 等于该组行数；每个分组内次数单调不增；文件内无重复题面；合计行数等于快照去重后的总数。
5. **构建**：`pnpm --filter @kxh4892636/wiki build`（`onBrokenLinks: throw`，坏链会挂）。侧栏是 autogenerated，顺序由 `sidebar_position` 决定，不用改 `sidebars.ts`。
6. **与知识笔记对账**：`020-计算机` 的笔记第一条 H2 是「常见问题」，抄的就是这些八股原文；改完对一遍已经迁走的题别再出现。

## 已知坑

- **文件没有 front matter `id`**（现存 2 篇全没有）：不能被 `doc:<id>` 引用，引一次就是 404（[003](../../questions/003-doc引用写错为什么build不报错.md)）。要引用先补 id。
- **「1736」不是缺题**：那是「题目 × 公司」的行数，唯一题 849；三种切法都指向同一批题，别重开排查（spec 的 [002](../../plans/archived/2026-11-12-八股文题目整理/002-排查差额题目来源.md)）。
- **多选题接口要末尾斜杠**：`api/question.json/` 不带斜杠恒返 `count: 0`。它比 `allcate_question` 多给 `difficulty` 与 `resource1..3`，要做「题目 + 参考链接」才用它。
- **题面按纯文本行输出**：含反引号、`<`、`{` 的题面要按行内代码或反斜杠处理；2026-11-12 那版 720 行里有下划线 2 条（`CLOSE_WAIT`、`TIME_WAIT`）、`A*算法` 1 条，都没让 MDX 报错。
- **`build/` 不会自动清理已删文档**：删了文件要重跑 build，才不会留下旧路由。
