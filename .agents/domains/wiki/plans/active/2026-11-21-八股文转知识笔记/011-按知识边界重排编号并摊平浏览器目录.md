# 011-按知识边界重排编号并摊平浏览器目录

## 背景

2026-11-21 晚用户提两点：

- `030-计算机网络` 下的 `100-浏览器渲染`、`110-浏览器缓存与内存`、`120-Web性能优化` 不需要单独目录，摊平到父目录；

## 决策

- 摊平后 `030-计算机网络` 25 篇连续编号：网络分层与 TCP/UDP 对比 → TCP 连接/可靠/拥塞/粘包 → UDP 可靠 → DNS → ARP 与路由 → HTTP 报文/方法/版本 → HTTPS → Cookie 与 JWT → 跨域 → Web 安全 → RESTful 与 RPC → WebSocket → URL 全流程 → 浏览器渲染/DOM/虚拟 DOM → 缓存 → 客户端存储 → 性能；
- 其余目录只改编号不改内容，frontmatter `id` 全部保持原值（短链依据）；
- 改名一律 `git mv`，形成环的（如 001↔002）先改临时名再落位。
