# 005-拆除轮转死代码

## 背景

004 把轮转改成「原会话内遮蔽历史」，`controller.create()` 那条链没了，于是：

- `src/client/rotation-follow.ts` 轮询 `/api/toolkit/nano-flow/rotation`，只为发现「会话 id 变了就跳转」；现在永远拿 `null`。
- `src/host/toolkit-routes.ts` 的 `rotation` 路由与 `src/contract.ts` 的对应字段，只为上面的轮询服务。
- 相关测试仍在跑一条不会发生的路径。

## 交付

1. 删掉 `client/rotation-follow.ts` 与其测试，清掉 `client/host-api.ts`、`client/index.ts`、`client/notes-dock.ts`、`client/panel.test.ts`、`client/index.test.ts` 里的引用。
2. 删掉宿主侧 `rotation` 路由、`contract.ts` 对应字段、`toolkit-routes.test.ts` 的用例；`nano-flow/session/rotate.ts`、`rotate.test.ts`、`mount-report.ts` **保留**（遮蔽逻辑本身还在用）。
3. 门禁：`pnpm test`、`vp check`、`pnpm build` 全过；测试数量下降要能对上删掉的用例。
4. 版本 bump 0.5.55，`pnpm pack` 后装入 web profile；**不重启宿主**。
