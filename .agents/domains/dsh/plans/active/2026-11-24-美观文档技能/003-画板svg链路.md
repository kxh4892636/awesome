# 003-画板svg链路

## 交付

- `scripts/larkify_svg.py`：内联 `<style>` / class 到 presentation attributes，映射色板，删除 pattern / clipPath / mask / filter，保留 marker，白底。
- `assets/lark-palette.json`：diagram-design 默认 token → Lark 色。
- `reference/diagram.md`：出图、Lark 皮肤、导出、转换、嵌入、回读与常见问题。

## 验收

- CSS 类驱动的 loop 示例：原样嵌入是黑块、文字消失；转换后节点、文字、箭头、焦点色均正常。
- 内联属性的 architecture 示例：转换后 pattern 被删、白底、焦点色变 `#245bdb`。
- 最终 demo 的 960×400 画板预览：文字可读、箭头完整、无黑块。

## 证据

- 黑块复现：`<whiteboard type="svg" path="@./loop.svg">`，预览 2026-11-24。
- 转换命令：`python3 scripts/larkify_svg.py loop.svg loop.lark.svg --palette assets/lark-palette.json`。
- 画板预览：`.temp/pretty-doc-demo/board-spacing.jpg`（本地临时文件，不入库）。
