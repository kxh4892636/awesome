# 004-发布并真机验收轮转

## 发布记录（2026-11-16）

- 版本 **0.5.53 → 0.5.54**，toolkit 仓提交 `6b5e9bd feat(nano-flow): 轮转改为同会话内遮蔽历史，子 agent 与 job 不再被杀`。
- 打包：`repos/dsh-toolkit/kxh4892636-dsh-toolkit-0.5.54.tgz`（`prepack` 已重跑构建）。
- 安装：`dsh plugin --profile web add <abs tgz>`；`~/.dsh/profiles/web/node_modules/@kxh4892636/dsh-toolkit` 版本为 0.5.54，`dist/index.mjs` 含 `compaction/prune`，`dist/nano-flow/` 资产齐全。
- `dsh --profile web --dump-config` 里 `@kxh4892636/dsh-toolkit` 正常组合。用裸 node import dist 会报 `ERR_MODULE_NOT_FOUND @deepseek-ai/dsh-home-paths`——这是 peer 依赖由宿主提供，不是缺包。
- 宿主仍在跑 0.5.53：bundle 只在启动时组合，**必须重启**才生效。

## 验收清单（重启后执行）

1. 版本证据：会话里让模型跑一次 `nano_flow_check` 之外的常规动作即可，但要确认宿主启动日志/面板显示 0.5.54；否则看到的是旧行为。
2. 触发重置：面板把 `rotateAt` 临时调到 0.001（或极低），发一条普通消息。
   - 会话 id 不变（会话列表里同一行，客户端不跳转）。
   - GUI 历史仍在，但模型新一轮按 seed 开局（回复会先复述 Plan 进度）。
3. 活体存活：重置**前**起一个后台 job（如 `sleep 120`）与一个子 agent；重置后两者仍在，结果仍能回收。这是本次改动的核心验收点。
4. seed 正确：重置那轮的 user 文本以「（本会话的上下文达到阈值，旧历史已被遮蔽…）」开头，含当前 Plan 与「绑定未变，无需再 bind」，末段是 `<reset-last-output>` 块。
5. Plan 连续：看板与 `<plan>/log.jsonl` 续在同一 Plan，没有多出绑定行；若本轮触发了重置，轨迹里那轮 `user` 已被 8 KB 上限截断。
6. 会话文件：`~/.dsh/sessions/<slug>/<sessionId>/session.v4.jsonl.zstd` 仍是同一个目录，日志只增不减。
7. 回归：非 nano-flow 预设的会话、子 agent 会话、上下文未达阈值三种情况都不触发重置。
8. 收尾：把 `rotateAt` 调回 0.618。

## 已知限制

- 旧的 `rotation` 路由与客户端跟随（`client/rotation-follow.ts`）现在永远拿到 `null`，功能无害但已是死代码，拆除留待单独收口。
- 遮蔽持久：重置后重启、fork、导出都看不到被遮蔽的历史（用户已确认观感可接受）。
