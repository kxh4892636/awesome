# 008-估值区改为K线下方双面板

## 需求（2026-11-17 用户）

- 估值区整体移到 **K 线下方**。
- 上下布局，与 K 线一致，一共两个面板：
  - 上方面板：时间周期 + 四个指标（PE/PB/PS/股息率），四个指标有选中态。
  - 下方面板：指标折线图；选中某个指标后，按该指标与所选时间周期显示对应的**分位数**折线。
- 参考截图：用户口述，无附图；以 K 线工具栏 + K 线画布的既有结构为准。

## 口径决策

- 指标为单选（一次只显示一条分位线），默认 PE；选中态沿用既有锈色 accent。
- 范围沿用 1Y / 3Y / 5Y / 全部，独立于 K 线周期；纵轴为「成立以来分位」（0–100）。
- 上方面板的四个指标按钮同时展示当前值与分位（如「市盈率 9.55 倍 · 89%」），口径日期放在下方折线图面板的头部。
- 状态按证券持久化：`valuationMetric` 单选 + `valuationRange`；旧记录缺字段逐项回退默认，不阻断。
- **2026-11-17 用户更正**：四个指标不做成 Segmented / 按钮条，保持原 2×2 数据面板形态（指标名、当前值 + 单位、历史分位刻度条），整格可点选，用选中态表达单选；不改读数排版。

## 非范围

- 不改后端、接口契约与 K 线行为；不新增图表依赖（沿用 SVG 自绘）。
- 不做多指标叠加、不做指标原值纵轴。

## 实现

- 页面顺序：摘要 → K 线 → 估值（两块 `Card`，作为页面 flex 列的直接子元素，宽度与间距跟 K 线卡片同源）；标题与 extra 的排版与 K 线卡片一致。
- 上方面板「估值指标」：范围用 antd `Segmented`（1年 / 3年 / 5年 / 全部，`aria-label="估值范围"`）+ `valuation-metrics.tsx` 的 2×2 面板。每个面板是原生 `<button aria-pressed>`，内含指标名、值 + 单位、历史分位与 0–100 刻度条；选中态是 `--color-accent` 的 3px 内竖线加 paper-2 底色，未选中面板的色块降到 0.35 透明度。键盘 Tab + Enter/Space 可切换，`:focus-visible` 用项目焦点色，命中高度 ≥32px。
- 下方面板「估值分位」：`valuation-chart.tsx` 只画一条分位折线（纵轴 0–100，横轴所选范围），悬停十字线给出日期、该指标值与分位；口径日期在卡片 extra（`口径 2026-11-16`）。分位为 null 的点断线不插值。
- 状态：`use-dashboard-view.ts` 的 `DashboardView` 由 `valuationMetrics: ValuationMetric[]` 改为 `valuationMetric: ValuationMetric`（默认 `pe`），`valuationRange` 不变；解析时旧记录里的「可见指标集合」数组按缺字段处理回退 `pe`，其余字段不受影响。
- 曲线模型简化：`buildValuationChartModel` 只取所选指标，输出 `{ metric, dates, percentiles, values }`，仍按范围锚点（四项里最新数据日）回退整年、抽稀 ≤300 点并强制保留最后一天。
- 状态处理：加载在两块面板内各放骨架（上面板四格骨架 + 读屏状态，下面板整块骨架）；失败与空数据收敛成一张「估值指标」卡片给出文案，不画空图。

## 偏差与风险

- 任务描述把口径日期同时写在上面板右侧与下面板头部；按 note 口径决策只保留一处（下方折线面板 extra），与 K 线「cache · N 条」同位，避免同一日期出现两次。
- 失败与空数据时只剩一张卡片（不渲染空的折线面板），属于有意的降级，不是漏渲染。
- 指标面板高 112px，超出 sloplint 对工具控件的 32–52px 预期，按「读数面板」waive；若以后真要把四格压成一条控件，需要重排读数与刻度条。
