# 003-估值查询接口

## 契约

`GET /api/valuations?symbol=<带后缀代码>` → `ApiResponse<ValuationsResponse>`：

```ts
interface ValuationsResponse { symbol: string; series: ValuationSeries[] } // 恒四项，顺序 pe/pb/ps/dividendYield
interface ValuationSeries { metric; points: ValuationPoint[]; latest: ValuationPoint | null }
interface ValuationPoint { dataDate: string; value: number; percentile: number | null }
```

- `value` 统一成比率：PE/PB/PS 是倍数，股息率 = 上游 DID ÷ 100（`0.04559` 即 4.56%）。
- `percentile` 透传上游 0–99.95 分位，不重算。
- 缺数据选**空数组**：`points: []`、`latest: null`；不用 null 序列，也不补 0。

## 与初稿的差异

- 路径是复数 `/api/valuations`（与前端约定一致），不是初稿的 `/api/valuation`。
- 未加 `startDate` / `endDate`：repository 已支持区间查询，等 005 真正需要曲线区间时再补参数，避免现在多一个没人用的参数面。

## 行为

- 先读缓存；`latestValuationDate(symbol)` 早于「应有最新交易日」（上海昨日起回退到最近的工作日）时，拉四个类型 upsert 一次。
- 上游失败但已有缓存 → 返回缓存；没有缓存才把 `MarketError` 交给 `handleError` 映射。
- 四指标全空（ETF 走 index 通道、目录外的代码）→ 1002；目录里没有的证券 → 1002「证券不存在」。
- 错误映射沿用现有口径：参数无效 1001（400）、无数据 1002（404）、上游不可用 1005（502）、超时 1006（504）。

## 实测（2026-11-16）

```text
GET /api/valuations?symbol=930955.CSI → 200，561694 字节
pe  2299 点 latest {"dataDate":"2026-11-13","value":9.5491,"percentile":89.3}
pb           latest {"dataDate":"2026-11-13","value":0.8981,"percentile":66.43}
ps           latest {"dataDate":"2026-11-13","value":1.5648,"percentile":98.43}
dividendYield latest {"dataDate":"2026-11-13","value":0.045592,"percentile":45.86}
GET /api/valuations                        → 400 {"code":1001,"message":"请求参数无效"}
GET /api/valuations?symbol=000001.SH        → 404 {"code":1002,"message":"证券不存在"}
```

- 响应 561 KB 是四指标全历史一次返回。004/005 若要首屏更快，补区间参数或前端截断即可，形状不变。
