# 009-估值指标单选用可点选读数面板

估值区改成「上方面板 = 范围 + 四个读数 / 下方面板 = 一条分位折线」后，指标只能单选。第一版把四个指标做成 `Segmented` 按钮条（复刻 K 线工具栏），用户当场否掉：这四个格子本来就是读数（指标名、当前值 + 单位、历史分位刻度条），压成按钮条等于用读数版面换一个选中控件。

决定：上方面板保留 2×2 读数面板，整格是原生 `<button aria-pressed>`；选中态只用 `--color-accent` 3px 内竖线加 `paper-2` 底色，未选中格子色块降到 0.35 透明度；读数排版（字号、间距、刻度条）一行不改。下方面板画所选指标的分位折线，切指标只换曲线，读数与范围都不动。

Considered Options：Segmented 按钮条（读数与选中控件二选一，已被用户否）；四指标多线叠加（量纲与辨识度问题见 006）；每指标一格自带曲线（卡片高度翻倍，且四张图不能同屏比较）。

Consequences：格子高 112px，超出 sloplint 对工具控件 32–52px 的预期，按「读数块」waive 39b；键盘只能 Tab + Enter/Space 切换（`:focus-visible` 用项目焦点色），命中高度 ≥32px；将来若要压成一条控件，需要重排读数与刻度条，不是换组件能解决。

验收：`valuation-section.test.tsx` 8 例覆盖默认 PE、点选只换曲线、范围只改窗口、缺分位不画线（2026-11-17，220 例全绿）。
